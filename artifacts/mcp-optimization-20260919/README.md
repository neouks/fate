# MCP 运行装配与上下文优化

## 实现

- 每个服务端装配器维护进程内工具元数据缓存，有效期 5 分钟，上限 128 个服务；不缓存连接、工具执行闭包或明文连接配置。
- 缓存键包含服务 ID、名称、传输、地址、命令、参数、环境/认证配置和 TLS 设置的 SHA-256。配置变化后重新发现；数据库可见性与启用状态仍在每次装配检查。
- 命中缓存时不建立连接；首次执行工具时建立该运行自己的连接并读取最新工具列表。正常结束关闭连接，已关闭运行不能重连，并发首次执行不会重复建连。
- 冷缓存或过期缓存仍在装配时发现工具；发现/握手共用 15 秒超时，失败不缓存为空列表。未做跨任务连接池或后台无限重试。
- Skill 门控、延迟工具执行策略和运行归属记录沿用原有链路。
- 在实际模型请求视图中，重复且完全相同的成功 SearchExtraTools 结果只保留最后一次全文；保留调用与结果配对。短结果、失败结果和其他工具不变。投影在压缩视图之后执行，不修改原始审计历史。
- 工具名称清单暂不缩减；冷启动的 Skill MCP 仍需发现一次。没有数据库迁移、前端改动。

固定三轮相同工具说明样例：模型消息 JSON 21,547 → 7,739 字节。该数字是模拟输入字节数，不是线上 token 或延迟测量；测试同时断言原始历史逐字节不变、最后一次说明完整、后续重复不在当前视图时保留原说明。
