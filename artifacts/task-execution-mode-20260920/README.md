# 托管／手工模式验收（2026-09-20）

## 已实现

- 任务持久化 `managed/manual`，旧任务默认托管；启动迁移及归档还原兼容。
- 意图使用现有 JSON payload 持久化 `dispatch_requested`，不增加生命周期状态，也不复用队列排序开关。
- 模式切换、领取与下发共用队列事务锁及服务端 Worker 控制锁。进入手工时清除未领取项选择，保留运行项；重复设置不清除选择。
- Planner 每轮读取模式，手工模式只规划；任务不因目标达成或空队列自动完成，超时保留。
- 主 Agent 新增意图与下发标记一起落库，重复待选意图复用；新增 `dispatch_intents` 仅主 Agent 可调用。任务准入失败撤回新增许可。
- 下发逐项验证任务归属、状态、关联资产及 URL 授权，合法项不受其他拒绝项影响；实际领取仍复核最新授权。
- 用户恢复和重跑明确下发；恢复 Worker 的消息入口复核任务状态，结束后不能重新领取。
- 页面增加模式切换、待下发／已下发展示、单项和多选下发、结束确认。结束取消当前执行，保留会话、意图及产出，不更改目标达成状态。
- 手工未选项在领取时提前跳过，不重复查询这些项的资产授权。
