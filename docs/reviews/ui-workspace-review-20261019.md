# 前端工作区改版验收记录

本次将 SERIES 前端统一为 Neo 风格工作区，使用 Mastra 风格的中性色、文字层级和细边框。任务顶部收敛为任务、发现、探索、文件、流量；Main 位于中央，Agent 过程位于可收起、调宽、放大的右栏。原有品牌、中文、主题、字体、侧栏配置和业务组件保留。

后端变更限于只读文件、流量正文、发现查询投影和任务关联会话查询。本次未调用 DeepSeek，未访问外部测试目标，未主动运行现有任务。并行产生的 Agent 后端修复作为既有工作合并保留，不计作本次 UI 功能。

## 路由和会话状态

保留 `/function/tasks/detail?id=...`。`tab=sessions/findings/graph/files/traffic` 对应五个主入口；`explore=graph/coverage/assets` 控制探索二级视图。旧 `overview/broadcast/asset-approvals/intercept` 映射到抽屉，旧 `coverage/assets` 映射到探索视图。已有意图、会话、活动和证据参数保留。

同一任务只建立一个数据控制层。切换标签不会卸载 Main；已经访问的图表页保留挂载，草稿和发现筛选按任务隔离。动态页面各自提供加载占位，首次打开审批或图表不隐藏整个工作区。标签选择对相同 URL 去重，避免 Radix 指针与焦点事件写入两条浏览器历史。

## 查询接口

| 接口 | 契约 |
| --- | --- |
| `GET /api/tasks/:id/files` | `ref/cursor/limit`；返回 `items/next_cursor`，列表上限 200；仅当前任务登记附件与可读意图工作目录 |
| `GET /api/tasks/:id/files/content` | `ref/offset/version/download`；文本每页最多 64 KiB，返回版本、偏移、总量、续读状态；变更返回 409 |
| `GET /api/traffic/exchange/:id/body` | `task/side/offset/download`；每次读取校验任务和实时授权；保持 base64 字节分页契约 |
| `GET /api/traffic` | 沿用任务过滤和分页，补充文件存储正文搜索；正文按有界窗口读取 |
| `GET /api/exploration/findings` | 搜索、严重性、状态与计数共用授权投影；旧图节点和继承记录可读 |
| `GET /api/conversations?task=...` | 返回直接绑定及漏洞复测关联会话，复测仍校验原漏洞可读性 |

文件引用由服务器解析；拒绝绝对路径、穿越、跨任务和符号链接。下载使用 attachment 与 nosniff，预览按文本或二进制提示展示。文件变更检测使用 inode、大小和修改时间。漏洞详情新增可选 `id_kind=record`，消除 finding 记录 ID 与探索节点 ID 碰撞，旧接口默认解释保持兼容。

## 复审结论与限制

复审还修复了同一 localhost 下多个端口的 Cookie 相互覆盖导致 SSE 401：显式 SSE 令牌优先于环境 Cookie，所有令牌仍严格校验签名和有效期。回归验证有效显式令牌不被无效 Cookie 干扰、无效显式令牌不能借有效 Cookie 绕过认证。

复审修复了标签重复历史、动态组件全页加载、工具详情重复取回、旧漏洞导出遗漏、记录 ID 碰撞、Retester 缺失任务关联以及大正文一次性加载等问题。文件权限检查、授权计数、暂停等待确认和原始消息合并保持服务端语义。

浏览器使用合成记录验证展示与交互，不把它等同于真实模型端到端执行。完整回归中的假模型终局响应已改为在 Worker 结束前排入，并在消费时读取真实事实引用，消除测试因晚追加响应而错过补位事件的竞态。任务运行逻辑以服务端回归为证；本轮未重新执行外部渗透测试。所有管理页完成入口冒烟，但未逐项保存所有配置组合，也未逐项重复测试每一种批量操作。现有设置页的 http-auth 已由后端移除，Shell 环境探针在隔离环境不可用；相关错误如实显示，没有伪装成功。
