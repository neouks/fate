# 八类 Agent 提示词轻量化验收与审查

本次在现有未提交修改上增量完成提示词统一、角色精简、上下文去重及回归。四份原有长角色正文从 **10,994 字节降到 2,296 字节，减少 79.12%**。相同本地输入和工具绑定的最新 DeepSeek 配对样本，总 token 从 **38,583 降到 29,736，减少约 22.93%**；字节压缩率不是实际 token 节省率，样本结果也不是生产费用承诺。

## 实施与配置兼容

- 八类角色共用版本化模板与单次变量渲染器。兼容两种 Goal 占位符，变量中的美元符号和其他占位符保持字面值；运行、预览及恢复默认共用来源。Retester 正式读取用户配置。
- 角色正文描述职责和关键调用时机，宿主单独装配必要完成协议。工具 description 保留实际调用语义，参数放在 Schema；不依赖自定义 system prompt 路径下未自动生成的 promptSnippet 工具清单。
- 一次性迁移只匹配已知旧内置模板指纹，追加版本并保留旧版；用户修改和主动回退保持生效。工具旧种子说明在运行时解析为当前内置说明，原存储内容保留，自定义说明优先。
- Planner 待办只注入一次；变化与态势中相同内容以引用衔接，不合并不同观察或来源任务。Worker 的执行约定和 objective 仅装配一份，资产索引明确不代表授权。
- Main 反馈使用 pi 原生持久 custom message，以活动 ID 去重；按未交付反馈分页读取，避免超过一页时永久遗漏旧消息。重启和后续轮次不重复注入。
- Goals、Worker、Planner、Reporter、Retester 在必要结果缺失时才提醒保存；已经提交的结果不会触发额外预算提醒。Reporter 定向触发与读取后的未保存报告会阻止假成功；Retester 必须保存明确结论。
- 原有角色工具权限、即时禁用、MCP/Skill 绑定、双图、锚点、资产审批、冷图压缩及一层来源任务只读继承保持。pi 继续负责循环、会话和压缩。

[八类候选正文](prompt-candidates-20261018.md)提供精简版本供对照。当前自定义提示词不会自动替换。新代码需随服务更新加载；加载后，配置在后续安全会话装配时生效。本轮未重启当前运行的管理服务。

## 自动化验收

服务端完整测试 **270 通过、1 跳过，24 个测试文件通过**。其中本次提示词专项 **25 通过**，上下文专项 **26 通过**，迁移专项 **51 通过**。唯一跳过项是共享测试库中缺少 DeepSeek 配置时跳过的模型列表集成用例，不计入通过；本次真实 DeepSeek 验收另列于下节。

覆盖八类实际角色装配、默认与自定义版本、旧默认升级及回退、特殊字符渲染、禁用工具、原生 Skill 索引、Main 跨轮与重启反馈、超过一页的反馈、Planner 待办去重及终态决策、Goals 必要提交、Reporter 保存提醒及 Retester 独立结论。原有回归继续验证授权变更、双图及冷图、幂等写入、去重、预算、租约、暂停恢复、关联任务和 pi 压缩后引用读取。

前后端类型检查、服务端构建、前端隔离目录生产构建及 `git diff --check` 通过。前端构建使用 webpack，没有改动运行中开发服务的构建目录。界面依赖现有模板编辑、预览、恢复和历史接口；本轮没有重新执行远端 A/B 目标任务或浏览器逐页验收。

最新 16 个配对会话全部通过，均未需要宿主追加补救提醒。包含精简迭代的 6 个已替代会话，以及另外 2 次真实宿主查询请求，本次累计 **61 次模型请求**，小于 64 次预算；从首轮对照开始到宿主探针结束小于 20 分钟。中间迭代结果保留在 `superseded_rows`，不混入最终配对汇总。

部分角色成本增加：Goals 新样本多执行了一次约束保存；Auto、Pentest 的初始角色提示补充了原来缺少的职责边界。不能把单次样本当作稳定统计，也不能声称每个角色都更省 token。未缓存输入从 11,196 降到 10,800；缓存读取从 23,040 降到 15,744；输出从 4,347 降到 3,192。费用需按供应商实际计价另算。

另外通过真实 Main＋数据库＋原生工具的宿主探针，验证实际请求边界记录：2 次请求完成进度查询，新增意图为零。运行配置保存首末请求体积及请求次数，只有大小和摘要哈希，不保存请求正文或密钥。该会话角色段为 659 字节，工具 Schema 为 9,590 字节，说明工具与动态上下文仍是输入的重要部分。

## 最终 REVIEW

已修复审查中新发现的重复预算提醒、反馈超过一页后遗漏、预览与运行特殊字符渲染不一致、Retester 配置被绕过，以及 Reporter 未保存报告仍可能结束的问题。最终已知范围内未发现由本次改动引入且未关闭的 P1/P2。

边界仍需明确：任意命令是否在语义上推进某一意图，不能只靠短提示词证明；权限、出口、工具集合及结果归属仍由宿主检查。未知自定义文本保留原样，其长度和内部矛盾不会被本次自动修正。模板预览不会连接 MCP 或执行模型，未知工具 Schema 不伪装成零成本；运行时诊断才包含实际启用工具和 Skill 索引。启发式 token 估算和供应商实际 usage 分开记录。
