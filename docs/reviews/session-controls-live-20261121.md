# 会话模型与上下文显示回归（2026-11-21）

## 故障与根因

用户实际访问 `http://127.0.0.1:8787/function/tasks/detail?id=4902`。认证后的 `session-model` 和 `session-usage` 请求都返回 `404 {error: "not found"}`：运行中的后端编译产物没有新增路由，而前端已经调用这些路由。3000 端口还在服务另一份旧前端构建，与此前验证的 Mock 和独立构建不是同一交付入口。

前端另有错误处理缺陷：模型列表与会话配置由 Promise.all 一起读取，一个接口失败就使模型列表也无法显示；错误文本直接透传，没有重试入口；用量失败与尚无记录都只显示破折号。

## 修复及运行状态

- 后端重新生产编译、平滑重启，沿用原数据目录和启动配置。保持 `SERIES_DISABLE_SCHEDULER=1`，没有启动任务或模型推理。
- 3000 前端更新到通过生产编译的 `.next-ui-review`，8787 仍为统一访问入口。该构建目录正在使用，重新构建应使用另一目录并在验证后切换。
- 模型列表与会话配置独立接收结果，显示加载/失败状态；404、服务失败使用中文说明及统一 Alert/Button 重试入口。
- 保存失败不展示成功提示；用量失败显示“用量暂不可用”，与“上下文未记录”区分。
- 主 Agent 历史会话为只读；当前会话可切换模型。截图中的历史会话已恢复显示 deepseek-flash，4.7% / 1M。
