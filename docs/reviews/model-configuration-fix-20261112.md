## 官方口径与修复

依据 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 和 [Anthropic 兼容说明](https://api-docs.deepseek.com/guides/anthropic_api/) 核对当前 deepseek-flash：默认开启思考、高强度；原生档位为 low/high/max，旧档位 minimal→low、medium/xhigh→high、ultra→max。Anthropic 的 budget_tokens 不生效，因此不再依赖该字段控制强度。

| 配置 | 修复后的行为 |
| --- | --- |
| 思考开关 | 显式关闭优先于强度；压缩请求可独立关闭思考；默认遵循供应商默认值 |
| 思考强度 | OpenAI 发送 reasoning_effort；Anthropic 发送 output_config.effort；Responses 发送 reasoning.effort；不混发协议字段 |
| 旧思考配置 | 兼容已有 thinking_type=medium 等记录；编辑界面显示实际档位，切换模型时调整兼容档位 |
| 上下文窗口 | 0 为本地默认 128K，正数按千 Token 换算；它是容量声明，不会扩大供应商实际容量；Planner/Worker 压缩阈值仍独立生效 |
| 输出上限 | 保留请求级较小上限；DeepSeek 设为 0 时省略协议上限，普通 Anthropic 保留 SDK 默认；连接诊断最多 4096 输出 Token |
| 请求限速 | 同一配置跨 Agent/任务共享数据库限速，秒和分钟限制取更严格间隔；不是 Token 限额或并发数；请求取消后不再新预约 |
| 流式 | 按当前实际候补配置决定传输与增量展示，不能沿用首个配置的开关 |
| 代理、会话头、图片 | 保留现有能力；校验代理协议及头名，拒绝覆盖认证和传输头；图片开关仅声明能力，文本连通性测试不验证图片能力 |
| 模型候补 | 修复开关未持久化、默认配置排序错误；按固定优先顺序候补，不宣称轮询均摊；冷却中的配置不能被重新补入候选 |
| 重试 | 仅暂时网络/服务故障重试；参数错误不盲目重试；-1 关闭生效；固定间隔不再被截为 10 秒；最长 1 小时 |
| 无效项清理 | 移除独立空响应、断流层和意图重跑的配置控件；断流归入模型请求重试。历史值只读保留，不冒充有效设置 |
| 配置预览 | 新增只读 /api/llm/preview，与保存、运行共用解析器，不启动模型；展示实际档位、窗口、输出字段和最小请求间隔 |
| 配置生效 | 保存后在下次会话装配时生效，界面不再承诺全部 Agent 立即生效 |

主要实现：pi/profile-policy.ts、pi/retry-policy.ts、pi/providerFromProfile.ts、pi/modelResolver.ts，配置路由与 LLM 管理界面。runner 仅补充候补后的流式状态读取；保留其其他既有修改。
