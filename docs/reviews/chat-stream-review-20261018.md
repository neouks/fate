# 对话分组与实时流式修复验收（2026-10-18）

本轮修复对象是任务对话、独立会话和复测过程展示。保留工作区原有未提交修改；没有修改 pi 模型循环、角色权限或双图调度语义。所有新增验证使用合成资料，目标请求为零。

## 修复结果与复审

| 问题 | 修复与主要位置 |
|---|---|
| 一次回复被拆成多个气泡，结束提示另占气泡 | `web/src/lib/conversation-turns.ts` 按宿主 `turn_id` 和角色、意图、会话段分组；共享 `transcript.tsx` 在同一张卡片内依次显示正文和折叠过程，完成状态放在页脚 |
| 流文本无法被最终消息可靠替换 | Main、Goals、Planner、Worker、独立会话、Retester 保存 `turn_id`；pi 文本和思考使用同一消息的 `stream_id`，以 channel 区分；最终活动保存相同身份 |
| 只有模型结束后才显示文字 | `engine/live-stream.ts` 每 75 ms 合并更新 PostgreSQL 快照；`http/activity-stream.ts` 发布快照与兼容增量；前端直接更新收到的文本，不模拟打字 |
| 最终提交时卡片短暂消失 | 服务端先读取快照、后读取活动；发送时排除已提交的消息。前端收到快照移除时同步提交待处理活动，避免 50 ms 批处理队列造成空档 |
| 用户消息重复、快速切换后串回旧会话 | 请求标识与持久用户记录合并；双向去重；会话数据按作用域隔离；迟到的初始化结果不覆盖用户选择 |
| 重复发送可能重复执行 | Main 在会话租约内检查请求标识；独立会话使用持久唯一标识。发送异常先查接收记录，不自动重新执行 |
| 独立会话和 Retester 没有流式 | 新增 `/api/conversations/:id/messages/stream`；Auto、Pentest、Reporter 和复测过程使用同一个事件订阅与 Transcript |
| 断线清空文字、代理失败后永久停流 | 保留已收到内容；原生 EventSource 处理普通断线；代理 502/503 导致 CLOSED 时，从最新持久游标重新连接，切换和授权撤销会取消重试 |
| 未完成却显示完成、提前显示停止 | 只有持久终态才显示完成或停止；等待模型、执行工具、等待审批、中断和停止确认分别显示；正常中断的部分正文转存历史并清理临时快照 |
| SSE 阻止旧进程退出 | `preClose` 主动关闭长连接。复验同时检查旧 PID 退出、新健康版本与浏览器恢复，避免把旧连接误判为重启成功 |
| 滚动抢位置、分页扩展同一卡片时跳动 | 使用原生 MessageScroller。针对“同一卡片内部前插”额外保存可见活动位置；原生 API 只能定位消息，不能定位卡片内部的活动。用户主动滚动会取消补偿 |
| 长内容、原文和附件展示 | 正文使用 Markdown，工具参数与结果配对且可展开；附件使用现有 Attachment；保留历史分页、来源定位和审批组件；窄屏内容在卡片内滚动 |

复审额外检查了慢数据库时的快照积压、定时器异常、旧执行器写入终态、增量晚于最终活动、代理暂时不可用，以及停止后的临时记录清理。快照写入会合并等待中的变化；会话／复测终态受执行令牌约束。当前发现的本轮 P1、P2 已修复并有对应回归或浏览器复验。

## 接口与兼容

- 历史和实时活动新增 `turn_id`、`stream_id`、`channel`，原有字段保留；身份同时保存在 metadata 中。
- SSE 保留普通活动事件和 `delta`；新增 `streams` 全量活动快照、`run_status` 与 `access_revoked`。增量含偏移，完整快照负责补偿，持久活动负责最终替换。
- Main 和独立会话发送接口接受可选 `request_id`；旧调用方仍可不传。
- 普通 API 与 SSE 默认同源，继续支持 `NEXT_PUBLIC_SSE_BASE` 显式覆盖。
- 迁移只新增会话 metadata、运行请求标识和临时快照表／索引。旧活动不改写，能够确定的用户／规划／终态边界用于保守分组。
- 正常停止把未结束的部分文本转存历史；进程意外中断留下的快照会过期并显示中断，不能冒充仍在执行。

### 八类入口

| 入口 | 展示和流式证据 |
|---|---|
| Main | 确定性模型真实 HTTP 入口、工具前后正文、多轮、停止、刷新、断网；DeepSeek 两轮 |
| Goals / Planner | 独立角色身份、两张规划卡片、共用规划会话入口；完整服务端回归覆盖原生执行链 |
| Worker | 当前意图独立卡片、工具原文、跨进程发布的实时快照和最终替换 |
| Auto | 原生会话回归、真实 SSE、DeepSeek 两轮、刷新和重启恢复 |
| Pentest | 原生会话专项回归与独立页面合成过程展示 |
| Reporter | 原生报告保存专项回归、独立页面、长代码和分页展示 |
| Retester | 原生结论保存专项回归、漏洞详情中的过程入口、跨进程发布的实时快照和最终替换 |

Worker／Retester 的浏览器增量夹具直接向共享快照发布合成文字，用于验证展示传输链路；它们不是新增真实模型执行。没有把这类夹具称为八角色真实模型验收。

### 真实 DeepSeek 用量

本轮 **8 / 8 次请求**，全部成功；Main 4 次、Auto 4 次，工具分别为只读 `list_findings`、`list_tasks`。只使用本地合成资料，未访问被测目标，也未修改正式模型默认配置。

SDK usage 汇总：input 6267、cacheRead 15104、output 482、totalTokens 21853。费用字段为 0 是 SDK 未配置价格，不代表供应商免费。追加的 500 次额度累计使用 **311 次**，剩余 **189 次**；账本已更新。本轮初次 UI 探针暴露了重复记录和完成状态竞态，不能当作最终通过证据；最终复验保存在 `deepseek-browser-final.json`。

## 发布、回退与限制

- 正式入口：`http://127.0.0.1:5173` → 后端 `8787`，代理 `8788`。
- 验收入口：`http://127.0.0.1:13000` → 后端 `18787`，代理 `18788`。
- 服务版本：`chat-stream-verified-20261018`。隔离验证使用 `13900`／`19787`，没有把测试库用于正式服务。
- 发布前后核对任务状态、暂停和排队标志；既有正式 2 个任务、验收 21 个任务保持原状。未主动恢复任务，未操作线上 B。
- 前端使用独立构建目录；此前 `.next` 构建仍保留，可用于临时回退 UI。数据库新增字段可被旧代码忽略，无需删除历史或回滚数据表。回退旧 UI 会失去本轮分组和恢复改进。
- 本地测试不等于所有生产反向代理的性能保证；外部 nginx/CDN 的缓冲和超时仍需部署侧验证。意外断电后的执行恢复由原有租约和会话机制负责，本轮不重新执行模型或扩大执行权限。
