# Agent 管理接口与交互修复验收

## 已确认根因与修复

- 前端调用 `DELETE /api/agents/:key`，后端缺少路由，返回通用 not found；现已补齐自定义角色删除。
- 同时补齐元信息 PATCH、提示词历史 GET 和变量 GET。不存在的角色明确返回 404，非法创建参数返回 400，重复 Key 返回 409。
- 原详情返回平铺 camelCase，而编辑器读取 `agent.max_turns` 等嵌套 snake_case，导致真实配置变成界面默认值；现在保留旧平铺字段并补齐编辑器契约，包括模型候选、可见资源、收尾配置及历史版本。
- 列表绑定数量使用数据库记录。提示词版本写入锁定所属角色，避免同时保存产生重复版本号。
- 删除与触发调度、会话准入及领取共享互斥边界。排队、运行或持有有效会话租约时拒绝删除；七类平台角色及其他 builtin 角色不能删除，可停用。
- 自定义角色删除清理提示词、变量、资源绑定、工具绑定和触发器；会话、活动、证据及计量保留。已删除角色的历史会话只读，历史 Key 不允许重新分配。已停用角色拒绝新消息排队。
- 列表/详情失败不再伪装为空或未找到；删除失败保留确认窗口，支持重试；处理中禁用重复提交。
- 正式页面复验发现加载时默认值短暂可编辑的问题，已改为配置加载成功后才开放表单。
