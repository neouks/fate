# Planner 自然收尾与任务终态验收

2026-10-18。本轮验证最新 TypeScript 后端与 pi 原生循环的完整任务结束过程，并修复收尾、恢复和结果提交的宿主缺陷。最终真实 DeepSeek 验收中，单意图自动任务、两阶段串行任务、手动下发后转自动收尾均进入 `done`；所有 Planner 轮次自然结束。保留现有自定义提示词、工具绑定、双图、审批、冷图与来源任务设计，未修改 pi SDK 源码。

本轮新增额度使用 **303 / 500 次物理 DeepSeek 请求**，剩余 **197 次**；加此前 72 次，累计 **375 次**。全部使用本地合成资料，真实目标请求为 **0**。请求台账跨重跑共享，在物理 fetch 边界计数；一次失败连接也计入额度。

| T4 P1 | Planner 最后一轮与暂停竞态，暂停后的任务可能被标完成 | 锁定任务行并检查暂停、排队、删除状态；已有终态不重复发布成功事件 |

| T6 P2 | 只运行 Planner、未派出 Worker 的任务没有 first_run_at，任务超时永不启动 | 实际执行 Planner 时启动时钟，与 B 的实际规划起算语义一致；模型配置查询和排队仍不计作首跑。验证目标未达成时进入 timeout，不伪造 done |
