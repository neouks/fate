# Skill 与 MCP 原生调用统计验收（2026-11-12）

## 结果与计数口径

原生调用的身份采集、持久化、统一查询及界面已补齐。生产发布版本 `f5fcca44-resource-usage`，5173 为正式前端，8787 为后端，8788 为代理。保留其他未提交功能及全部业务数据、配置，没有调用真实模型、连接用户 MCP 服务或访问外部测试目标。

- Skill：原生 `read` 读取 Skill 根目录下的 `SKILL.md` 算一次尝试。索引加载、辅助文件、`bash` 自行读取不计入；读取成功也不等于模型已正确运用其中全部内容。
- MCP：通过原生扩展实际注册的工具身份记录调用尝试。工具搜索、连接测试、资源枚举不计入；失败和宿主拒绝单列，不能当作成功执行。
- 每条记录以执行器 ID、原生响应序号和工具调用 ID 确定身份。同一回执重复投递、同一会话重新读取不加次数；下一次真实调用即使参数相同仍单独计数。
- 角色、任务、独立会话、意图、执行轮次和会话文件身份来自宿主。绑定任务的独立会话只保存一条记录，同时可归属两个维度；不能将任务总数和会话总数再次相加。
- 成功、失败、进行中与结果未知分开。执行器消失且未取得可靠结果时为未知；后续恢复到原生结果可以补齐，不补造成功。
- 旧 `skill_usage/mcp_usage` 保留并标为历史来源、结果未知。启用前未采集的调用不猜测回填；界面零值表示“没有已记录调用”，不表示历史从未使用。旧缺失 Skill 清单明确为旧版记录。

## 实现与恢复边界

`resource_usage` 与 `resource_usage_results` 是无正文、无凭据的计量表，不随任务、会话或 MCP 配置删除。原生扩展采集精确的 MCP 服务与工具身份，不从带下划线的工具名称猜测。Skill 按目录绑定身份识别，不使用可冲突的 frontmatter 别名。

计量投影复用已存在的活动 outbox、事务和原生 SessionManager 文件恢复。在工具执行前持久保存开始回执；结果可以由工具活动或原生会话文件补齐。结果先到、开始回执后到也能关联。重放仅投影记录，不重新执行模型或业务工具。存储本身损坏或没有任何持久回执的历史无法保证恢复，明确保留未知。

列表、详情和 MCP 单工具调用数使用同一聚合。完整统计不受最近调用列表的 limit 影响。统计读取失败展示错误，Skill 切换忽略旧请求返回，MCP 请求使用序号防止迟到响应串入另一服务。
